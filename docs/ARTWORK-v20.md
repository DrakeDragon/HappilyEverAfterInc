# v20 artwork inventory and production prompts

Created with built-in image generation. This cumulative release adds 30 image sheets: 19 permanent-shop sheets, four guest portrait sheets, six charm sheets, and one currency sheet. The four v19 PNGs remain bundled.

The original generated PNG masters are preserved in the local working release folder. The deployable ZIP carries quality-94 WebP delivery versions for these thirty new sheets, reducing download size while retaining the original dimensions. This is format optimization, with no repainted content or resolution change. The four earlier PNG assets remain unchanged.

## Mapping and use

- Shops: five columns × six rows per sheet. Entries 0–29 use `shops-REALM-0.png`; entries 30–49 use `shops-REALM-1.png` where present. Realm indices follow the game's progression order, not the older realm-environment atlas order.
- Guests: four columns × five rows; guest IDs map to portrait cells in existing GUESTS order.
- Charms: four columns × four rows; flatten CHARMS in realm order, six per realm.
- Currency: four columns × five rows. First seventeen cells match the sixteen permanent realms plus Event; final cells are quill, sand, and puzzle piece.
- `assets/art-manifest.json` records each shop/guest/charm name, sheet, and cell. The game embeds compact equivalent mappings and dimensions; it does not fetch the manifest.
- Cells are read left to right, top to bottom. Unused shop cells are atmospheric filler and are not assigned to gameplay entries.
- Thumbnails preserve image proportions with a centered crop inside the card; the reference gallery shows the complete cell.
- Managers and shop upgrades reuse associated business art. Weekly event businesses use the existing illustrated festival symbol. Guest portraits and collectibles are static images.
- All artwork files must be deployed with the game. No image generation service or API key is required at runtime.
