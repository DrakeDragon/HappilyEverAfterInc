# v21 Cat expressions

The Cat expression sheet was edited from the existing generated narrator portrait using built-in image generation. It preserves the violet/turquoise fur, emerald eyes, gold collar, and star pendant.

Delivery asset: `assets/cat-expressions.webp`, quality 96, original 1215 × 1295 resolution, alpha transparency. The original generated PNG is preserved in the local release folder; the deployable ZIP contains the WebP delivery version.

Layout: two columns × two rows. Cell 0 calm, cell 1 delighted, cell 2 winking, cell 3 sleepy. `setCatExpression()` selects the cell; CSS supplies gentle breathing and speech motion. This is expression swapping over painted portraits, not skeletal animation or true lip sync.

Reference: `assets/cheshire-cat.png` from v20.

Production prompt:

Edit/reference asset: provided original violet-and-turquoise Cheshire Cat portrait. Create a production expression sprite sheet, exactly two columns by two rows of equal square cells, transparent background. Same individual cat in each cell: preserve fluffy purple fur, turquoise stripes, emerald eyes, pink nose, golden collar and emerald star pendant, same centered head and upper chest composition, same scale, identical camera angle and painterly dimensional premium storybook art. Comfortable 10% empty margin inside every cell, no overlapping cells, ears and whiskers fully contained. Change ONLY facial expression: top left calm knowing smile with open eyes; top right delighted celebratory wide smile with bright open eyes; bottom left curious playful wink, one eye shut; bottom right peaceful sleepy smile with both eyes closed. Entire sheet truly transparent, no scenery or backing squares, no text, no labels, no borders, no watermark. Clean exact 2x2 aligned grid.
